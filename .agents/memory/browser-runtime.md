---
name: 浏览器测试运行环境
description: Nix 环境中下载版 Chromium 与环境提供的浏览器的兼容性差异。
---

在本工作区运行持久化浏览器测试时，优先使用环境提供的兼容 Chromium，而不是为下载版浏览器追加全局系统依赖。

**Why:** 下载版 Chromium 曾因缺少 `libglib-2.0.so.0` 无法启动；同一套测试使用环境提供的浏览器即通过。这是运行环境兼容性问题，不是应用故障。

**How to apply:** 先检查 `/repl/tools/bin/chromium` 是否仍存在，再通过测试配置的可执行文件覆盖参数指定它；不要仅为浏览器测试变更部署配置。

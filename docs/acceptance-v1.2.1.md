## 发现的问题与必要修复

发现并修复两项UI问题：

1. 菜系三态按钮原来约42×29 CSS px，手机上触控区域偏小。给现有按钮增加 `min-h-11 min-w-11`，保证最小44×44 CSS px。补验54个按钮全部达标，两端表单没有横向溢出。
2. 房间原来只显示已提交人数，没有独立展示已加入人数。新增一行人数标记，直接显示已有 `participantCount/requiredParticipantCount`，原提交进度保留。使用新测试房间在尚未提交时验证加入数1/2→2/2、提交数保持0/2；两端390px无横向溢出。没有新接口或新状态逻辑。

以上都只修改 `artifacts/duoxing/src/App.tsx`，没有重新设计页面或改变匹配、事件、持久化和状态流转。

未发现其他阻断本次双用户流程的功能问题。旧版本提交产生的400为预期拒绝，不计为缺陷。
